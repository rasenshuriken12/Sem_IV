# Operating System

An Operating System (OS) is software that manages computer hardware and software resources. It acts as a bridge between users and the computer, ensuring smooth operation. 

Components of an Operating System: 

- **Kernel** is the core component of the operating system that manages hardware (CPU, memory, devices) directly.
- **Shell** is the outermost layer of the Operating System that handles user interaction and acts as an interface, translating user commands into instructions for the kernel.

Think of the kernel as the engine and the shell as the steering/controls.
