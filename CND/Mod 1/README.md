### What is a "Reference Model"?
In networking, a "reference model" describes **what** needs to be done at each stage of communication, but it doesn't prescribe **how** to do it. It serves as a standard blueprint that all networking technologies should follow.

### The Core Philosophy: Peer-to-Peer Communication
The most important concept in the OSI Reference Model is that each layer on one computer communicates logically with the same layer on another computer. They are "peers."

7. Application Layer: 
- `window` for appln services, to access the network and for displaying the received information.
- determines the amount and type of data generated by user applications, known as `Generated traffic`. This helps network designers planning bandwidth and network capacity, to ensure efficient communication.

6. Presentation Layer:
- converts data from the sender’s format into a `common format` so the receiver can understand it. Eg. ASCII → BCD, Little Endian → Big Endian.
- `Encryption` converts plaintext into an ciphertext before sending it. At the receiver side, decryption,
- `Compression` reduces the size of data before transmission so fewer bits are sent through the network.

5. Session Layer

This layer controls the lifecycle of a communication session.
- `Establishment`: Before data exchange starts, connection between two applications. `Maintenance`, `Termination`.
- maintains the `Synchronization` of clocks.
- allows half-`duplex` or full-duplex connection at application level.

4. Transport Layer
- `Segmentation` and Reassembly: Breaks msg into smaller units
- A single computer may run many applications at the same time. To identify which application should receive the data, the Transport Layer uses `Port numbers`.
- Connection-Oriented Service: Before sending data, a connection is established between sender and receiver. Eg. TCP
- Connectionless Service Eg. UDP

3. Network Layer
- Routing: selects best path for data to travel from source to destination.
- Logical Addressing: Each network is identified by an Addressing scheme like IP Address.

2. Data Link Layer
- Framing: It adds special bit patterns at the beginning and end of the data to mark the frame boundaries.
- Physical addressing: adds MAC address in the header of each frame.
- Error control: detects and retransmits damaged or lost frames.
- Flow Control: Controls the flows of data thru acknowledgement.

### Difference Between OSI Model and TCP/IP Model

| No. | OSI Model | TCP/IP Model |
|----|-----------|--------------|
| No. of Layers | Consists of 7 layers | Consists of 4 layers |
| Acronym | OSI (Open System Interaction) | Transmission Control Protocol / Internet Protocol | 
|  Developed by  | ISO | DoD ( Dept. of Defense) |
| Layer Separation | Application, Presentation, and Session are separate layers | These three layers are combined into a single Application layer |
| Protocol Implementation | OSI model was developed before the protocols were implemented | model was defined after protocols were implemented |
| Model Concept | separates services, interfaces, and protocols | does not separate services, interfaces, and protocols |
| Reliable Delivery of Packet | Guaranteed | Not |
